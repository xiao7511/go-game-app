# 掼蛋交互与音频优化

2026-10-11，验证地址 `http://127.0.0.1:5178/game.html`，进入掼蛋单机对局。

## 完成内容

- 倒计时固定在“出牌”按钮正上方，PC 与小屏横屏均居中且不挡按钮。己方回合最后 10 秒每秒播放一次短提示音；出牌、离开对局或切换回合后停止提示。网络对局使用服务端 deadline；旧联机计时只作提醒，不替服务端推进回合。
- 移除其他玩家的“思考中”和上一手牌型气泡；保留“不出”、完游及己方选牌反馈。
- 炸弹、天王炸与同花顺触发 1.4 秒爆炸动画和独立效果音，重复渲染或同步同一手牌不重播。动画不阻挡点击，支持减少动态效果的系统偏好。
- 登录头像支持 `avatar_url` / `picture`；本机预设或上传选择按用户 ID 保存。旧联机席位广播头像并在座位旋转时保留玩家 ID；权威服务从认证用户元数据读取头像，写入快照并支持恢复与下一副牌。
- 增加 19.2 秒循环原创背景音乐。首次交互后播放，默认音量 35%，尊重已有音乐开关与音量偏好；设置中可独立调节音乐、游戏效果及倒计时提示。返回大厅或进入后台停止音乐。

后续音频升级将 19.2 秒原创背景音乐替换为三首舒缓古典录音，并以真实爆炸录音替换合成炸弹音效，设置中可选择与试听。当前来源与生成方法见 [音频来源与许可](guandan-audio-provenance.md)。账号头像没有时保留稳定默认头像；上传选择保存于当前设备，通过旧联机席位广播共享。
