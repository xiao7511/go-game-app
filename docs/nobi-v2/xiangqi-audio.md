# 中国象棋走棋音效与 PC 验证

普通落子使用短促木质敲击声 `assets/sounds/xiangqi-move.wav`（0.16 秒）；吃子使用更厚重的双段木质撞击声 `assets/sounds/xiangqi-capture.wav`（0.26 秒）。两者均为本项目程序合成的原创音效，无外部录音或运行时网络依赖，可通过 `node scripts/generate-xiangqi-audio.mjs` 重现。文件为 44.1kHz、单声道、16bit PCM，峰值保留余量并对尾音衰减。

人机双方均在合法走棋提交后播放。联机以服务端确认的相邻一步状态为准，房间初次载入、重复快照、悔棋、跨多步重连恢复均保持静音；后续新走的一步照常播放。选子、再次点击取消和落点预览不会触发落子声。

“更多”增加音效开关，与主页的游戏音效开关共享持久化设置和音量；与背景音乐独立。页面进入后台时沿用共享音频管理器暂停，不缓存旧音效，恢复后不补播。

PC 验证入口：`http://127.0.0.1:5178/game.html?game=xiangqi&mode=SINGLE`。建议先走兵或马，再尝试炮吃马；分别检查选子/取消无音、确认后一次音效、人机回应、吃子差异、关闭音效后仍能走棋，以及悔棋不播放。两个 PC 浏览器账号进入象棋房间后，双方新落子应各播放一次，刷新或重连不重复播放历史动作。

自动化覆盖合法动作判定、静音的状态恢复、PCM 文件可解码及真实 HTMLMediaElement 播放、PC 人机吃子、双账号联机和重复快照。联机用隔离服务与明确标识的模拟账号，不操作生产对局。

本次验证结果（2026-10-17）：先运行 PC 音效专项 2 项，均通过；随后完整单元测试 219 项通过，象棋与联机视口相关浏览器回归 9 项通过。PC 浏览器记录实际媒体播放成功并解码两种 PCM 文件，覆盖人机双方和双账号联机。Web 与 Mobile 静态资源构建及资源一致性检查通过；本次未生成新的原生安装包。
