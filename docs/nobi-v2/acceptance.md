## 3. 平台与视觉

- PC Chrome/Edge 的 1366×768、1920×1080；其他支持浏览器按明确兼容矩阵验证，不据此声称所有浏览器通过。
- Android/iOS 小屏竖屏（如 360/390 宽）、横屏、安全区、DPR 2/3、软键盘、触摸拖选、系统返回/手势实际验证。
- 设备最低系统与最低 WebView/Safari 版本须由实际工具链和测试结果确认，不把现有 minSdk 22/iOS 13 等同于全部业务功能都兼容。
- 移动 UI 有 V2.1 正式稿文件/版本/哈希映射及逐页对照；大厅深蓝主题与游戏内部旧风格边界清楚。
- 增加一个测试游戏注册项即可出现卡片/平台过滤/模式，不修改大厅硬编码分支。
- PC CS 卡片保留；Windows 安装/未安装、协议有无、单机/联机、API 异常、昵称编码分别验证。
- Android/iOS 包与页面不含 CS 卡片、安装文件、下载链接或协议拉起；直接构造 CS 路由仍被拒绝；移动浏览器也不可提供拉起。
- APK/IPA 有真实构建/安装记录；iOS 必须在 macOS 工具链和设备验证。本轮未执行。

## 4. Supabase 与鉴权

隔离环境至少准备用户 A/B/C、匿名、观战者，并以各自 token 调用接口：

| 操作 | 通过条件 |
| --- | --- |
| 配置缺失/非法 URL/CDN或网络不可达 | 明确错误，不进入半初始化联机 |
| 注册需要邮箱确认/已有 session | 正确显示下一步，不假定注册等于登录 |
| 直接访问游戏/邀请、session 过期/refresh、退出 | 使用真实 Auth UID；未认证不发起受限动作；退出释放频道 |
| A/B 读写本局，C/匿名访问 | 允许所需参与者动作；越权读写、抢位、改对手 ID 被拒绝 |
| 广播伪造身份、座位、轮次/手牌 | 服务器/授权层拒绝；对手只能看到自己的手牌 |
| 更新个人昵称/metadata.rank | 可更新允许的展示资料；不能改变积分或授权 |
| 数据库重建/迁移重跑 | schema/权限/RPC契约完整、幂等；旧游戏仍兼容 |
| 产物和客户端扫描 | 无 service_role、私钥、数据库密码；公开 anon key 不充当权限防线 |

生产实际策略仍属未验证；以上需要真实版本下的负向测试，不仅 SQL 字符串检查。

## 5. 排行榜与个人排名

- 单机、AI、未验证历史/异常结果不入竞技分，游戏与周期正确隔离。
- 候选结果伪造分数/胜者/参与者失败；同局重复请求、超时重试只产生一次积分事件。
- 并发结算不丢分；错误事务不留下半个战绩或统计。
- 掼蛋队友真实身份与每人结果一致；CS 无可信战报时不计分。
- Top N 和个人卡片以同一规则/快照显示，名次与积分一致；同分同名次，分页稳定。
- 新用户为“暂无排名”；空榜、加载、错误、离线明确展示；不把 mock 当真实数据。
- 从积分流水可以重建统计并审计异常；撤销/纠错有受控版本，不允许客户端直接改 stats。

## 6. 音乐与音量

- 首次无用户操作不强行播放，操作后能开启；autoplay 拒绝和音频缺失有可恢复状态。
- master/bgm/sfx 0/50/100、音乐开关和静音逐项验证，gain 有效且 0 为静音；既有音效服从音效设置。
- 游戏间切换只存在一个壳级背景音乐实例，进入/退出/反复登录无重叠播放。
- 刷新/重启恢复偏好，退出账号不抹掉音量；非法偏好值被限制到合法范围。
- Android/iOS 后台/锁屏/来电中断停止，恢复符合用户原选择，禁后台持续播放。
- CS 拉起失焦不残留大厅音乐；音频失败不影响游戏规则。
- 曲目有来源与授权记录，原生离线音频资源完整。

## 7. 发布前门槛

发布包严格白名单、不含签名材料/node_modules/审计证据；应用与数据库回滚可演练；Web 根域/子路径/native 全部资源可达；缓存更新不缓存 Auth/API 或残留旧版；真实业务测试与已知风险状态随版本交付。

不自动修改 main，不自动执行生产 SQL或部署。本轮只生成审计提交；实际发布在后续阶段授权后实施。
