# 安卓 1.0.5：中国象棋与联机画面联调

本次在中国象棋首版上修复联机画面溢出。旧掼蛋横屏规则给外层 iframe 设置了 390px/320px 的最小高度，优先级高于全屏房间规则；小屏横屏会因此超出 WebView。现移除旧规则，让进行中/结束房间的画面由固定定位四边确定，内层游戏处理安全区，避免重复扣除。大厅的长昵称、连接提示允许换行，确认弹窗可滚动。

安卓版本 `1.0.5` / `versionCode 6`，包名 `cn.obsmd.gogame`，沿用既有测试签名，可覆盖安装。联调包名为 `Nobi-android-1.0.5-usb-20261016.apk`，只放在忽略的 `dist/mobile-device/` 和手机 Download，不作为正式网页下载包。

## 联调方式

1. 电脑启动 `npm run dev:online:server`，服务健康检查应包含 `xiangqi`。
2. 手机连接 USB 并允许调试，执行 `adb -s <设备序列号> reverse tcp:55440 tcp:55440`。
3. 生成资源：`node scripts/prepare-mobile-test.mjs --platform=android --usb-test`，按既有安卓工具链构建并验证资源和签名。
4. 将 APK 推送到 `/sdcard/Download/`，在手机手动更新安装，使用现有账号登录。此包联机依赖电脑和 USB；单机象棋不依赖联机服务。
5. 第二个不同账号在电脑 `http://127.0.0.1:5178/online.html?game=xiangqi` 加入房间，房主开始。检查走棋、确认/取消、悔棋/求和、聊天、返回大厅、刷新恢复及横竖屏切换。围棋和掼蛋也检查棋盘/手牌与操作按钮是否完整。
