# Nobi 参考图界面升级

本次根据用户提供的移动端参考图调整现有游戏界面，保留工作区中已有的头像、选牌、牌桌与围棋改动。

## 界面与交互

- 大厅采用深蓝夜景、金色品牌字和按钮，掼蛋与围棋使用场景大图。掼蛋封面叠加现有原始牌面，56 张受保护 PNG 未修改。
- 电脑保留三栏大厅；手机保留五项底部导航和安全区域。游戏入口按平台能力显示，CS1.6 仍只提供电脑入口。
- 手机子页面增加标题与返回入口。音乐、设置、战绩、通知与关于页面返回个人中心，底部“我的”保持选中。
- 个人信息、统计与常用菜单排列在头像选择器之前，便于进入战绩、排名和音乐设置。
- 排行榜前三名展示领奖台与头像，当前用户行高亮。前三名保留可访问的列表标签；后端未提供排名时显示空状态。
- 音乐设置保留独立开关、音量保存、试听与恢复功能，新增场景卡片；背景音乐尚无授权曲目，界面会显示实际可用状态。
- 统一对局工具栏与设置面板的蓝金风格，保留原有牌桌布局、选牌逻辑、棋盘及落子渲染。
- 修复掼蛋按钮按压时缩小触控区域的问题：保留下压反馈，按住与释放过程中仍维持至少 44px 的目标尺寸。

## 主要文件

- `ui/reference-upgrade.css`：独立的参考图样式层。
- `ui/lobby.js`：大厅卡片、返回导航、个人中心顺序、排名头像与音乐场景。
- `game.html`：加载样式层。
- `scripts/verify-build.mjs`：验证新增样式与场景图的构建完整性。
- `tests/browser/reference-upgrade.spec.mjs`：验证子页面返回、键盘焦点、头像保存和小屏排行榜。

## 验证

2026-10-11 验证结果：

- `npm test`：19 个测试文件、133 项单元测试通过。
- `npm run test:browser`：37 项 Edge 浏览器测试通过，耗时约 1.8 分钟。
- `npm run build`、`npm run build:mobile`：Web 与 mobile 构建通过。
- `npm run verify:assets`：56 张原牌面 PNG 与 7 处受保护围棋渲染检查通过。
- `npm run verify:build`：Web/mobile 的脚本、样式、图片、音效与平台隔离检查通过。

首轮浏览器回归发现 852×393 横屏按钮在按压反馈中缩到 44px 以下；已通过保留位移、取消缩放修复，并新增持续按压的回归测试。Windows 沙箱的临时文件与服务启动限制阻断过测试，最终单元和浏览器测试在获准的沙箱外环境完成。
