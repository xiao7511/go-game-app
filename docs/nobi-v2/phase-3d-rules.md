## 基线审计

旧 makeDeck/startNetworkGame 实际已支持两副 108 张和每人 27 张，single-hand 标识表示单局；Phase 3C 报告中的“单副牌”描述有误。旧 typeOf 对逢人配过度放行、王炸分支顺序、自然连续点数、同花顺压制和钢板支持不足；旧服务固定级牌 2，无多轮或贡牌。保留 legacy-rules.ts 供无版本/旧版本快照恢复；禁止旧模式新建竞技房。旧积分保留在 legacy 规则分区，新规则独立从 1500 开始；历史显示其版本。
