# Phase 2 启动条件

2026-10-10。依据[Phase 1 实测交付](phase-1-report.md)。

**GO：用户视觉验收、授权范围内的只读核验、隔离测试环境与原生工具链准备。NO-GO：生产迁移/上线、可信积分对外发布、签名分发。**

## 已具备

- PC/手机真实大厅、共享注册表与同源构建；没有全量重写掼蛋/围棋。
- 55 单元 + 12 Edge 浏览器回归，原 38 + 6 保留；原 56 PNG / 7 围棋区域、App copy PASS。
- 本地排名 provider、加载/重试/空状态/演示隔离，不依赖未知生产表。
- 统一音频设置、三个音量域、四场景、交互解锁和中断取消；未供应 BGM。
- [真实截图](screenshots/phase-1/README.md)、运行指南与资源清单。

## 建议顺序与门禁

| 下一项 | 启动所需 / 验收标准 |
| --- | --- |
| 视觉确认 | 用户验收手机 V2.1 方向、卡片与交互；补 PC 参考或批准当前三栏实现；不能声称已逐像素匹配缺失图 |
| Supabase 契约 | 用户/DBA 批准只读连接或提供脱敏 catalog；核实上海实例 game/public、Auth、资料 RPC、房间字段、RLS、Realtime；不执行生产迁移 |
| 测试环境多人 | 与生产隔离的账号/房间；创建、加入、退局、并发、重连、多局、序号和权限否定测试；私密手牌不向所有玩家广播 |
| 可信排名 | 服务端规则裁决、结果签名/审计、幂等结算、赛季/同分/好友范围定义与权限测试；客户端 metadata 和广播不能作可信积分 |
| BGM | 所有者提供许可或原创授权、来源/归属/期限/平台/曲目文件；构建白名单和来源清单审核后，再实际验证渐变、首播、循环与中断 |
| Android | 配置 SDK/Gradle/设备；真实 Debug APK、WebView/320px/横竖屏/触控/安全区、硬件返回与前后台/电话/耳机 |
| iOS | Mac、Pods/Xcode、真实 Simulator/设备；Safari/WKWebView 布局、DPR/安全区、音频与生命周期；Windows copy 不是 IPA 证据 |
| 安全与发布 | 签名身份所有者批准迁移/换钥或撤销方案；旧依赖受控升级；单独批准部署后验证缓存版本、旧 SW、域名/API 与回退 |

本轮没有新数据库表、真实积分结算、好友或通知服务；没有新商业音乐。外部 CS 包、协议安装、服务器 API 与联机仍 NOT VERIFIED，不自动执行 BAT/VBS/注册表。

## Phase 2 不应扩张的边界

不合并 main、不强推、不改 Bundle ID/Auth 键/协议、不变动原牌面和围棋风格。没有新授权前不处置证书/历史材料、不执行生产 SQL、不部署。既存 CRITICAL 私钥暴露仍是发布阻断；ignore/白名单不能使已泄漏材料恢复保密。

下一轮建议用户明确批准“测试环境与只读契约验证”的范围，并提供 PC 参考、测试 Supabase 连接方式和 BGM 授权资料。这些缺口不阻止现在本地预览，但阻止宣称产品可上线。
