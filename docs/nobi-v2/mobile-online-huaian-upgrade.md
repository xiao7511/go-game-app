# Nobi 游戏 · 联机与移动端升级（2026-10-12）

## 功能

- 围棋联机沿用单机棋盘布局；显示实际登录玩家昵称、头像和执色，去除房间号与复制链接。对局操作集中在可收起的操作面板，悔棋需要双方确认。
- 游戏大厅选择的游戏决定房间目录、建房和恢复范围，掼蛋与围棋房间互不混列。
- 房间聊天使用服务器成员校验、SQLite 持久化和 SSE 同步，显示最近 50 条，保存最多 500 条；每条最多 200 字，发送重试按消息标识去重。文本安全展示，消息不影响对局版本。
- 围棋和掼蛋分别选择《月光》《夜曲》《梦幻曲》，沿用已有录音授权，独立保存曲目；音乐偏好在页面之间同步。
- 登录与返回大厅时刷新账号信息；胜率和战绩来自本人参与的实际服务端好友对局。正式竞技积分仍由既有积分服务提供，好友对局不生成虚构积分或排名。
- 手牌区再次点按已选牌可归位；拖选使用 8px 横向阈值，松手保留手牌 DOM，避免点选回退时节点被替换。
- 新图标为蓝底、白色圆角框内 N；Web、Android 和 iOS 均更新。iOS 1024px 图标为不含透明通道的 RGB PNG。

## 淮安规则与兼容

按 [DB3208/T 235—2025 官方标准](https://dbba.sacinfo.org.cn/portal/online/c05d0c20a7d5e0337cfd834a1d35cf78c8d7095f31a46876885d164dacabdbe2)的全程赛方式实现，标准自 2025-05-02 起实施。涵盖双副牌、逢人配及牌型大小、进还贡与抗贡、借风、升级和打 A；首次翻牌排除大小王及红桃 2，持该物理牌者先出。逢人配按较大合法解释处理，两张配牌搭配相邻两对首出按钢板处理。打 A 未过继续保留 A。

单机与联机共用 `ui/guandan-engine.mjs`。新房间版本为 `guandan-huaian-2025-v1`；已存在的 `guandan-standard-v1` 房间继续使用原配置、解释优先级和升级行为，持久化重放仍可恢复。此应用实现全程赛，不包含限时赛事的比赛管理流程。
