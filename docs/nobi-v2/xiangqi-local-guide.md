# 中国象棋首版与本地验证

## 已实现

- 大厅新增“中国象棋”，桌面和移动端均可选择人机或好友联机，使用独立的木纹棋盘和红黑棋子。
- 人机：可执红或黑，入门/标准/进阶三档；AI 在 Worker 中限时搜索，支持提示、整轮悔棋、重开和翻转。
- 操作：选子显示合法落点，再次点击取消；点目标后按“确认走棋”。手机横竖屏均适配，主对局界面固定一屏，无需滚动。
- 联机：两人建房/加入、红方先行、真实账号昵称头像、回合倒计时、服务端合法性校验、SSE 同步、刷新重连、冷启动恢复；悔棋和求和必须对手确认。房主移除等待玩家、好友邀请、战绩和聊天复用现有服务。退出返回大厅，保留登录。
- 棋谱、将军提示、将死/困毙、认输、双方和棋；背景音乐复用围棋的本地古典音乐设置与现有授权文件。

## 规则范围

规则标识 `nobi-xiangqi-casual-v1`，为休闲版本，暂不计积分。落实七种棋子走法、蹩马腿、塞象眼、九宫/河界、炮架、兵卒前进与过河横行、将帅照面和应将约束。将死与困毙均判负，棋局在将死时结束，不以吃掉将帅为操作目标。

同一局面（含轮到哪方）出现三次：若循环中仅一方每步将军，该方长将判负；其他情况判和。连续 120 步无吃子且无兵卒前进判和。本版不实现竞赛长捉的全部细分裁定，已在“玩法说明”中说明，不宣称符合完整比赛规则。

基础走法参考：[GNU XBoard 中国象棋规则](https://www.gnu.org/software/xboard/whats_new/rules/Xiangqi.html)、[世界象棋联合会规则资料](https://www.wxf-xiangqi.org/index.php?Itemid=304&id=208&lang=en&option=com_content&view=article)。休闲循环裁定为本项目显式规则，并非完整 WXF 竞赛裁定。

## 本地体验

先开启两个终端，在项目根目录分别运行：

```powershell
npm run dev:online:server
```

```powershell
$env:NOBI_DEVICE_ONLINE='USB_LOCAL_AUTH_VERIFIED'
npm run dev:online
```

浏览器打开 `http://127.0.0.1:5178/game.html?game=xiangqi`，可先试“进入单机版”。直接启动：`http://127.0.0.1:5178/game.html?game=xiangqi&mode=SINGLE`。

联机入口：`http://127.0.0.1:5178/online.html?game=xiangqi`。用两个不同的已有账号，分别在两个浏览器或独立浏览器配置中登录；一方创建房间，另一方从列表加入，人数到齐后房主开始。不要把账号密码填入聊天或测试文件。单个账号不能占据双方席位。

服务只监听本机 `127.0.0.1:55440`，比赛/聊天保存在忽略的 `.nobi-isolated/xiangqi/manual-rooms.sqlite`。仅通过既有线上 Auth 的只读用户接口验证身份，不写线上积分或账号数据库；正常启动不使用模拟账号。云服务旧版本不具备象棋能力时，客户端会明确提示升级，不会误建掼蛋房间。

## 验证与发布

```powershell
npm test
npm run check:authority
npm run test:xiangqi:integration
npm run build
npm run build:mobile
npm run test:browser
```

自动测试包含初始局面的 44 种合法走法和两步 1,920 个局面、特殊走法、将死/困毙、循环裁定、限时 AI，以及真实 HTTP/SSE 双账号对战、权限、幂等、悔棋/求和确认、聊天与数据库冷恢复。浏览器测试覆盖桌面与手机横竖屏、Worker、选子取消、落点确认、执黑、音乐、未读聊天和退出。

当前为本地验证版。正式发布时需先发布包含 `server/xiangqi.ts` 和 `ui/xiangqi-engine.mjs` 的联机服务，再发布网页，随后重新生成安卓/iOS 包；既有已安装包不会自动增加游戏。原有围棋/掼蛋房间和签名配置保留；不对生产积分架构增加未经验证的新游戏结算。

手机对局界面采用固定一屏布局：竖屏棋盘与常用操作同屏，横屏玩家资料位于右侧、棋盘按可用高度放大。音乐、翻转、执棋颜色、难度、认输/和棋和棋谱从“更多”进入；仅次要弹窗可以滚动。
